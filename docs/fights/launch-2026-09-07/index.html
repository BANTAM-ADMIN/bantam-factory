How to read a fight card Clocks, checks & conditions +

PASS requires both accepted work and clean completion. OUTPUT_ONLY means the artifact passed but the run did not finish cleanly. A timeout is not time to successful completion. Missing token counters remain unknown, never zero.

A BANTAM-only card records one system's work; it is not a win against absent competitors. Comparisons retain their complete planned roster. Separately recorded frontier references retain their own conditions. These are selected development tasks and individual observations, not a universal ranking or a held-out reliability study.

Time bars show elapsed run time, not progress or correctness. Local and frontier models are distinguished in the replay. Read each card's conditions for configuration and accounting details. Public downloads omit private transcripts and source. This static site loads no external assets and sends no telemetry.
