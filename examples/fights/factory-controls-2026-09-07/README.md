# Factory controls · fresh work orders

Two additional development/demo tasks, distinct from the six original launch
work orders. Implement an auditable literal-redaction planner and repair a
retry-budget controller. These tools exercise useful factory responsibilities;
passing a coding task does not automatically install or promote its candidate
into BANTAM production code.

Each work order specifies a pure API and CLI, with five independent acceptance
groups. Starter public tests are protected. Reviewer solutions are never mounted
into contender workspaces. Freeze this kit before running any live contender;
retain every attempt and any rejected protected-file modification.
