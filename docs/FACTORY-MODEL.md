# Big jobs. Chicken problems.

A capable model can still waste a day looking in the wrong place, repeating a
bad edit, or calling unfinished work done. BANTAM FACTORY gives that worker a factory:
the relevant inputs, useful tools, checks, and a path back when something fails.

We call the manageable, checkable pieces **chicken problems**.

```text
Your job → Context + tools → Build → Check → Finished work
                              ↑        │
                              └─ Repair┘
```

The factory formula is simple:

- **Bring the right material.** Make the relevant project context available.
- **Equip the worker.** Give it tools that turn decisions into working changes.
- **Check the result.** Run the tests and catch incomplete work.
- **Use the failure.** Feed concrete problems back into the next repair.

## The factory can build its own equipment

A repeated chore is a good next job. Ask BANTAM FACTORY to build the script, parser,
checker, or tool that makes it easier. A fight card can produce useful software
and a record of how well the factory built it.

Its [self-improvement workflow](SELF-IMPROVEMENT.md) goes further: study recurring
friction, build a change to BANTAM FACTORY, test it, and adopt eligible improvements.
That cycle is experimental and explicitly started by you.

The ambition is a factory that gets better at your work through experience.
The [fight cards](https://bantam-admin.github.io/bantam-factory/) show what it
can deliver today.
